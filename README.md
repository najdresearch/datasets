# Najd Datasets

Source repository for rights-cleared dataset manifests, transformation code, and dataset cards used by Najd Research. Data bytes and large artifacts belong in approved storage, with immutable source and license references here.

No employer material or private evaluation cases may be committed. The existing Hugging Face Najd Benchmark collection is a candidate source, not automatically a reviewed benchmark. First milestone: define one source ledger and review protocol for a narrow Saudi/Arabic decision-task set.
